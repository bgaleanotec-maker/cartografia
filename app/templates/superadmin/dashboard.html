Integración API — Otros Proyectos

Otros proyectos (Doctor, etc.) pueden enviar notificaciones usando el endpoint REST con su API Key.

# Ejemplo Python — push de notificación desde otro sistema

import requests

requests.post(

'https://tuapp.com/api/notifications/push',

headers={'X-API-Key': 'tu_api_key'},

json={

'target_username': 'bgaleanotec',

'title': 'Nuevo paciente asignado',

'type': 'task',

'source_project': 'doctor',

'link': 'https://doctor.app/paciente/42'

}

)
